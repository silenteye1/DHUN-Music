## ✨ Features

- **Ad-Free Streaming:** Listen to your favorite tracks from YouTube Music without any interruptions.
- **Modern UI/UX:** Built entirely with Jetpack Compose for a smooth, material-designed experience on Android and Desktop.
- **Cross-Platform Base:** Powered by Kotlin Multiplatform (KMP).
- **No Promotional Popups:** Stripped of intrusive rating cards, blog banners, or star requests.
- **Custom Playlists:** Seamlessly manage local and YouTube-synced playlists.
- **Background Playback & Lyrics:** Full support for media controls, caching, and synchronized lyrics.

## 🛠️ Tech Stack

- [Kotlin](https://kotlinlang.org/)
- [Kotlin Multiplatform (KMP)](https://kotlinlang.org/docs/multiplatform.html)
- [Jetpack Compose](https://developer.android.com/jetpack/compose)
- [Koin](https://insert-koin.io/) (Dependency Injection)
- [Coil3](https://coil-kt.github.io/coil/) (Image Loading)
- [Ktor](https://ktor.io/) (Networking)
